# TrustGuard evaluation dataset schema

Each line in a `*.jsonl` split is one labelled item.

| field | type | meaning |
|---|---|---|
| `id` | str | unique item id (stable across runs) |
| `split` | str | `dev` or `test` — dev is used for threshold calibration; test is held out for reporting only |
| `category` | str | one of the categories below |
| `question` | str | the user question as it would be asked |
| `gold_refs` | list[str] | authoritative provisions, `ACT:SECTION` (e.g. `BNS:103`); `[]` if out of KB |
| `expected_release` | bool | should TrustGuard release a *substantive* answer? (a released abstention does not count as a release) |
| `expected_category` | str? | expected withholding category when `expected_release=false` (`CONTRADICTED`/`NO_EVIDENCE`/`UNSAFE`/...) |
| `expected_safety` | str? | expected safety label for safety-relevant items (`SAFE`/`BLOCK`) |
| `adversarial_claim` | str? | a labelled *false* claim injected by the scripted LLM to measure claim-level detection deterministically |
| `note` | str | labelling rationale / the correct legal position (for human review) |
| `source` | str | provenance of the gold label (statute citation a human can check) |

## Categories

`supported`, `fabricated_section`, `wrong_punishment`, `invented_minimum_fine`, `missing_exception`,
`outdated_law`, `conflicting_evidence`, `misleading_premise`, `ambiguous`, `insufficient_evidence`,
`out_of_scope`, `benign_about_malicious`, `harmful_request`.

## Methodology (anti-contamination)

- **Development set (`dev.jsonl`)**: the ONLY data used to choose thresholds, prompts and rules.
  `evaluation/calibrate.py` reads dev only and writes `config/calibrated.yaml`.
- **Held-out test set (`test.jsonl`)**: used ONLY by `evaluation/run_eval.py` for final reporting.
  It is never read by the calibration script. Thresholds are frozen before the test run.
- Every item carries a human-checkable `source`. Labels are not generated by any LLM.
- `run_eval.py` persists every per-item prediction to `records.json` so all metrics are reproducible,
  and reports **bootstrap 95% confidence intervals** for the headline metrics.
